# ShadowNet AI — Frontend

React + Vite client for the ShadowNet platform. All setup and usage instructions are in the **[root README](../README.md)**.

## Quick commands

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```

Ensure the API is running on port **5001** (`cd ../server && npm run dev`). Optional: copy `.env.example` to `.env` and set `VITE_API_PORT` if you change the API port.
